# Customizing Sublayer

This section provides detailed guidelines and examples for creating custom components to extend the Sublayer framework. Through customizing Generators, Actions, Agents, and Triggers, developers can create highly tailored automation and processing solutions.

## Custom Generators

Generators are responsible for generating specific outputs based on input data. They focus on a single generation task. When creating a custom generator:

- Define the interface methods that need implementation, such as `initialize`, `generate`, and `prompt`.
- Use the `llm_output_adapter` to specify the expected output format.
- Implement the logic for prompting the large language model (LLM) and processing the results.

## Example

```ruby
class CustomGenerator < Sublayer::Generators::Base
  llm_output_adapter type: :single_string,
    name: "example_output",
    description: "An example output generated by the custom generator."

  def initialize(input_data)
    @input_data = input_data
  end

  def generate
    super
  end

  def prompt
    <<-PROMPT
    Here is a prompt using input data: #{@input_data}
    PROMPT
  end
end
```

## Custom Actions

Actions perform specific operations to either retrieve inputs for a generator or act on the generated output. When creating custom actions:

- Define the `initialize` method to accept necessary parameters.
- Implement the `call` method to execute the action.

### Tips:
- Ensure actions are small and reusable.
- Consider actions as steps in a workflow or as utility tools.

## Custom Agents

Agents perform tasks autonomously, typically in response to specific triggers. When creating a custom agent:

- Define key methods: `trigger`, `goal_condition`, `check_status`, and `step`.
- Use triggers to define when the agent should react.
- Implement an iterative step to work towards the defined goal.

## Custom Triggers

Triggers activate agents based on certain conditions or events. When defining a custom trigger:

- Implement the `setup` method to configure the trigger conditions.
- Use the `activate` method to make the agent take a step when the condition is met.
