# Welcome to Sublayer

Sublayer is a model-agnostic AI agent framework for Ruby. It empowers you to build AI-powered applications by combining Generators, Actions, and Agents in a simple and intuitive way.

## Get Started

Dive right in with our [Quick Start Guide]({% link docs/quick_start.md %}).

Understand the fundamental building blocks of Sublayer:

*   [Generators]({% link docs/concepts/generators.md %}): Learn how to create components that generate specific outputs based on input data.
*   [Actions]({% link docs/concepts/actions.md %}): Explore how to define operations for gathering inputs or utilizing generated outputs.
*   [Agents]({% link docs/concepts/agents.md %}): Discover how to build autonomous entities that perform tasks or monitor systems.
