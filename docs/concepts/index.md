# Core Concepts

The framework is broken up into three core components: **Generators**, **Actions**, and **Agents**. These elements form the backbone of the Sublayer architecture, each playing a distinct yet interconnected role within the lifecycle of an application built using the Sublayer framework.

## Generators

Generators are the building blocks of the Sublayer framework. They are responsible for generating specific outputs based on input data. Generators focus on a single generation task and do not perform any actions or complex decision-making independently.

* [Learn More About Generators]({% link docs/concepts/generators.md %})

## Actions

Actions serve as operational entities within the framework. They are responsible for executing specific operations to acquire inputs for a Generator or to take actions based on the output generated by a Generator. Unlike complex decision-making units, Actions are straightforward in their operation, often compared to tools in other agent frameworks.

* [Learn More About Actions]({% link docs/concepts/actions.md %})

## Agents

Sublayer Agents act as autonomous assistants, designed to automate tasks and respond to events or changes within their environment. Agents are highly adaptable and can manage a variety of tasks from monitoring to processing and automating workflows. They leverage the capabilities of Generators and Actions to fulfill their objectives.

* [Learn More About Agents]({% link docs/concepts/agents.md %})

### Interconnection and Lifecycle

- **Interfacing**:
  - **Generators** interact with the data ecosystem, generating outputs based on dynamic input data. They often work in tandem with **Actions** to utilize this generated output effectively.
  - **Actions** enable the practical execution of tasks using the outputs provided by Generators. This can include data transformation, system interactions, or triggering other tasks within the framework.
  - **Agents** orchestrate these components by utilizing **Triggers** to initiate tasks, **Goal Conditions** to define task objectives, **Check Status** routines to monitor progress, and **Steps** to execute defined actions, creating a cohesive workflow.

- **Lifecycle Management**:
  - The lifecycle of a task within the Sublayer framework begins with an *Agent Trigger*. Once active, the Agent evaluates its progress towards the defined goal condition, employing Generators to generate necessary inputs and Actions to facilitate processes.
  - This cycle repeats through monitoring and adjustment phases until the Agent achieves its goal, demonstrating dynamic and adaptable task management capabilities inherent in the Sublayer system.
