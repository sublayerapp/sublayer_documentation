## Architectural Overview

To help you better understand how the different components of the Sublayer framework interact, we've created an architectural overview. This section provides a detailed look at the relationships between core components such as Generators, Actions, and Agents.

### Component Relationships

In the Sublayer framework, components work together seamlessly to create powerful AI-driven functionalities:

- **Generators**: Create specific outputs from input data.
- **Actions**: Perform tasks with outputs or provide inputs.
- **Agents**: Autonomous units that trigger actions based on conditions.
