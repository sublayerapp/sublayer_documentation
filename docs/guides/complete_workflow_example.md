# Complete Workflow Example

This guide provides a comprehensive, step-by-step example of how to tie together the different sub-components of the Sublayer framework into a cohesive workflow. We will go through setting up a Generator, using an Action, and completing a task with an Agent.

## Overview

This example aims to unify multiple aspects of the Sublayer framework in a single workflow. We will:

1. **Set Up a Generator**: Guide through initializing a basic generator to process input and produce an outcome.
2. **Utilize an Action**: Demonstrate how to use actions to handle data generated by the generator.
3. **Execute an Agent Task**: Illustrate how to define and run an agent task that uses both the generator and actions.

## Step 1: Set Up a Generator

### Creating a Generator

Generators are responsible for generating specific outputs based on input data. To create a generator:

```ruby
require 'sublayer'

module Sublayer
  module Generators
    class MyGenerator < Base
      llm_output_adapter type: :single_string,
        name: "generated_output",
        description: "The generated output based on input data"

      def initialize(input_data)
        @input_data = input_data
      end

      def generate
        # Call super to send a request to the LLM
        super
      end

      def prompt
        <<-PROMPT
          Based on input: #{@input_data}, generate an appropriate output.
        PROMPT
      end
    end
  end
end
```

### Using Your Generator

To use this generator:

```ruby
input_data = "Input relevant data here"
generator = Sublayer::Generators::MyGenerator.new(input_data)
puts generator.generate
```

## Step 2: Utilize an Action

### Defining an Action

Actions are executed to perform specific tasks with the generator's output:

```ruby
module Sublayer
  module Actions
    class MyAction < Base
      def initialize(output)
        @output = output
      end

      def call
        # Perform an action with the output
        puts "Executing action with output: #{@output}"
      end
    end
  end
end
```

### Invoking the Action

Once the action is defined, you can call it after generating output:

```ruby
output = generator.generate
action = Sublayer::Actions::MyAction.new(output)
action.call
```

## Step 3: Execute an Agent Task

### Creating an Agent

Agents coordinate using generators and actions to accomplish tasks:

```ruby
module Sublayer
  module Agents
    class MyAgent < Base
      trigger_on_files_changed { ["input_file.txt"] }

      goal_condition { @task_complete }

      check_status do
        # Check if the task is complete
        @task_complete = true # Example condition
      end

      step do
        generated_output = generator.generate
        action = Sublayer::Actions::MyAction.new(generated_output)
        action.call
      end
    end
  end
end
```

### Running the Agent

To run the agent, simply execute:

```ruby
agent = Sublayer::Agents::MyAgent.new
agent.run
```

This example completes a cycle of using a generator to produce output, an action to act on it, and an agent to manage the workflow. Modify this template to fit the complexities of your specific application scenario.
